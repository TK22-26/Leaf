# F1.1.6.2: Azure-specific Features

Handle Azure DevOps behaviors that differ from GitHub without leaking Azure-specific complexity into the shared UI.

## Deliverables
- Iterations-based file diff support.
- Vote-to-review-state mapping.
- Thread and policy/status normalization.
- Capability gating for provider-specific limitations.

## Implementation Notes
- Use the iterations API for reliable PR file diffs and content comparison.
- Normalize reviewer votes into the shared review state model.
- Normalize thread state, resolved state, and policy results into the shared comment and check displays.
- Where Azure lacks a GitHub-equivalent capability, degrade visibly but gracefully.

## Acceptance Criteria
- [ ] Azure diffs can drive the shared diff viewer.
- [ ] Azure review votes and threads display meaningfully in the shared detail view.
- [ ] Unsupported provider differences are messaged rather than hidden.
