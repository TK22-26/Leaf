# E1.1.6: Azure DevOps Parity

Bring the same main-area pull request experience to Azure DevOps after the GitHub path is stable, including user/group reviewer search through identity APIs.

## Deliverables
- Azure DevOps provider adapter with identity search for reviewer autocomplete.
- Azure-specific diff, review, and policy mapping.
- Capability-aware parity with the GitHub-backed experience.

## Acceptance Criteria
- [ ] Azure DevOps repos show a `PULL REQUESTS` tree section when supported.
- [ ] Core list/detail/create/update/merge/close flows work through the same facade used for GitHub.
- [ ] Reviewer search uses Azure DevOps identity search API with server-side filtering.
- [ ] Azure-specific iterations, vote, thread, and policy differences are handled cleanly.
