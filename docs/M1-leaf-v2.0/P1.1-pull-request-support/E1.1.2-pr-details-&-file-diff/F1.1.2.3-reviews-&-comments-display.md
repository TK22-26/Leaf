# F1.1.2.3: Reviews and Comments Display

Add review summaries and comment threads to the PR detail view in the main content area using provider-neutral models and lazy loading.

## Deliverables
- Review state summaries and reviewer identities.
- General comments and file-thread comments in chronological order.
- Lazy loading and grouping rules that work for both GitHub and Azure DevOps.

## Implementation Notes
- Normalize GitHub review states and Azure DevOps vote/thread semantics in provider adapters.
- Keep rendering mostly read-only for this milestone; writing new comments is outside scope.
- Preserve file path and line metadata so comments can later link into diffs.
- Avoid loading all comments and reviews until the PR detail view needs them.

## Acceptance Criteria
- [ ] Review states display clearly for supported providers.
- [ ] Comments render in a readable order with author and timestamp.
- [ ] Azure thread metadata can be represented without provider-specific UI leaking upward.
- [ ] Large comment sets remain usable.
