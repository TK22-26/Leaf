# F1.1.2.4: Markdown Rendering

Provide a safe markdown fallback for PR bodies and comments in the main-area detail view.

## Deliverables
- Basic markdown-to-readable-text conversion for PR bodies and comments.
- Safe handling for links, lists, code fences, and headers.
- A clean seam for a richer renderer in E1.1.7.

## Implementation Notes
- Prefer a lightweight fallback first so the detail view remains readable without pulling in a heavy renderer immediately.
- Preserve link destinations in text form where appropriate.
- Keep the binding shape compatible with a future rich markdown control so the view does not need to be redesigned later.

## Acceptance Criteria
- [ ] Raw markdown syntax does not dominate the detail view.
- [ ] Common markdown constructs become readable plain content.
- [ ] The fallback path remains safe for provider content.
- [ ] Upgrading to a full renderer later does not require changing service contracts.
