# F1.1.4.3: Update PR Implementation

Support editing a pull request title, body, and draft state from the main-area PR detail view.

## Deliverables
- Update command path from the detail view in the main content area.
- Edit UI, either inline or dialog-based.
- Refetch and redraw behavior after successful updates.

## Implementation Notes
- Keep the editable fields limited to title, body, and draft state for this milestone.
- Use provider capability checks for draft conversion semantics.
- Preserve markdown editing as plain text in this phase; rich editing is out of scope.
- Refresh the selected PR after update rather than mutating many UI fields in place.
- Users can always edit via browser using the persistent "Open in browser" link.

## Acceptance Criteria
- [ ] Supported PR fields can be edited from Leaf.
- [ ] Updated content is reloaded and shown accurately.
- [ ] Unsupported provider cases degrade cleanly.
