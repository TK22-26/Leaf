# F1.1.4.2: Close PR Implementation

Support closing a pull request without merge from the main-area PR detail view.

## Deliverables
- Close action, confirmation, and service call.
- Post-close detail refresh and tree refresh.
- Clear provider error messaging.

## Implementation Notes
- Keep the action in the PR detail header or action bar in the main content area, with provider-aware enablement.
- Refetch or remove the PR from active filters after close depending on current filter state.
- Use event-hub refresh plus PR cache invalidation after success.
- Users can always close via browser using the persistent "Open in browser" link.

## Acceptance Criteria
- [ ] Users can close an open PR without merging.
- [ ] Closed PRs leave the active UI in a consistent state.
- [ ] Provider permission failures are visible and understandable.
