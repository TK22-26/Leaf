# E1.1.4: Merge, Close, Update, and Checks

Add pull request mutations to the main-area detail view while staying inside the current session and refresh architecture. All in-app actions are complemented by a persistent "Open in browser" link — users are never locked to Leaf or browser.

## Deliverables
- Merge dialog and merge execution.
- Close and update actions.
- Status checks and merge-readiness summary.
- Cache invalidation and event-hub refresh after mutations.
