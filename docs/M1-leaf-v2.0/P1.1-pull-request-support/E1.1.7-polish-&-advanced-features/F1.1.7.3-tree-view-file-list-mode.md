# F1.1.7.3: Tree View File List Mode

Add an optional directory-grouped file list inside the main-area PR detail view for large pull requests.

## Deliverables
- `PullRequestFileNode` or equivalent tree item model.
- Toggle between flat file list and directory tree within the PR detail view.
- Reuse of current tree styling where it improves consistency.

## Implementation Notes
- This is for the file list inside the main-area PR detail view, not a second top-level repository tree.
- Keep flat mode as the default because it is simpler for smaller PRs.
- Build the file tree from provider-neutral file data so GitHub and Azure DevOps share the same UI path.

## Acceptance Criteria
- [ ] Users can switch between flat and tree file list modes.
- [ ] Large PRs become easier to scan.
- [ ] File selection still opens the shared diff viewer in either mode.
