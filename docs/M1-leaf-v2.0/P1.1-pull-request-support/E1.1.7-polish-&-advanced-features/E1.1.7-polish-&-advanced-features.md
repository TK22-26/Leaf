# E1.1.7: Polish and Advanced Features

Improve performance, ergonomics, and readability after the core PR workflow is stable. Polish applies to the main-area detail view, create form, tree section, and content-mode transitions.

## Deliverables
- Pull request caching and request coalescing.
- Polished tree and main-area states.
- Optional file-tree mode inside PR details.
- Rich markdown rendering.

## Acceptance Criteria
- [ ] Common PR interactions remain responsive on medium and large repositories.
- [ ] Loading, empty, and error states feel native to the existing Leaf UI across all main-area modes.
- [ ] Content-mode transitions (graph ↔ create ↔ detail) are smooth and free of visual artifacts.
- [ ] Optional file-tree mode and rich markdown do not destabilize the core workflow.
