# E1.1.3: Create Pull Request

Create new pull requests via an inline form in the main content area, with reviewer autocomplete search and an actionable toast for post-create feedback.

## Deliverables
- Inline create form in the main content area (not a modal dialog) with source branch, target branch, title, description, reviewers (autocomplete), and draft toggle.
- Entry points: "+" button in PR section header and branch context menu.
- Reviewer autocomplete search using provider reviewer-directory APIs.
- Actionable toast built on the existing notification stack for post-create feedback with actions to open PR detail in Leaf or in the browser.
- Draft PR creation support.
- Preflight handling for missing upstream branches or unsupported remotes.

## Acceptance Criteria
- [ ] Users can open PR creation from the "+" button or branch context menu.
- [ ] The create form renders in the main content area, replacing the git graph.
- [ ] Accept/Cancel buttons at the bottom of the form control navigation back to the graph.
- [ ] Reviewer autocomplete searches users, teams, or groups from the appropriate provider path.
- [ ] The form validates source, target, title, and provider support.
- [ ] Draft creation works where the provider supports it.
- [ ] On success, an actionable toast shows actions to open PR detail in Leaf and in the browser.
- [ ] If merge/conflict or orphaned-conflict state is active, PR creation mode is blocked with an actionable toast instead of hiding the resolution UI.
- [ ] Branches that are not yet pushable or trackable are handled explicitly.
- [ ] Work items are NOT included (out of scope).
