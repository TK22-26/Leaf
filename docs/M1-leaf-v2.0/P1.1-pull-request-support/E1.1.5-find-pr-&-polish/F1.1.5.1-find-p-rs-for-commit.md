# F1.1.5.1: Find PRs for Commit

Add commit-to-PR lookup from the commit history context menu, navigating to the PR detail view in the main content area.

## Deliverables
- `Find Pull Request...` command from commit history.
- Provider lookups by commit SHA.
- Selection flow that loads the PR tree section (if needed), selects the matching PR, and switches the main area to PR detail view.

## Implementation Notes
- If one PR matches, select it and switch the main area to PR detail immediately.
- If multiple PRs match, present a small chooser and then activate the chosen PR.
- If the PR section is not loaded yet, load it first rather than opening a disconnected result dialog.
- Keep the final navigation inside the tree/detail model — the main area switches to PR detail view the same way it does when clicking a PR in the tree.

## Acceptance Criteria
- [ ] Commit context menu exposes PR lookup.
- [ ] A single match routes directly to the matching PR detail view in the main area.
- [ ] Multiple matches are handled without losing context.
- [ ] No match is reported clearly.
