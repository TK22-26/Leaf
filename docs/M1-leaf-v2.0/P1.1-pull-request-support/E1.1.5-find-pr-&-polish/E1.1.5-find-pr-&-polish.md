# E1.1.5: Find PR by Commit

Connect commit history back to pull requests so users can jump from a commit to the PR that introduced it, with the PR detail opening in the main content area.

## Deliverables
- Commit context-menu entry point.
- Provider lookup by commit SHA.
- Multi-match handling and squash-merge fallback heuristics.
